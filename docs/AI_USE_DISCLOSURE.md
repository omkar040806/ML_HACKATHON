# AI assistance disclosure

AI assistants were used during development for code generation and suggestions and for debugging; the team reviewed and edited the text. Every experiment reported here was run on the team's own laptops. The run logs and result files are in `results/` (for example `results/models/run_log.txt`), and every number in this report can be reproduced with the commands listed in `README.md` (seed 42). The evaluator-test partition was never used for training, feature selection, model selection or tuning. Its reference routes are read by the API only after a prediction has been made. In addition, the final system was scored once offline on the evaluator trips with a script (commit `99cc1d5`), whose results are in `results/evaluator/` and Section 8.1 of the report; it changed no model or decoder setting; Figure 7.2 of the report shows one live API request on an evaluator trip. No prediction is hard-coded. The team reviewed the results reported here, and each member can explain the parts of the code listed under "Repository layout" in `README.md`.
